☁️ Cloud Object Storage Drive - Installation Guide

Mount cloud object storage (Alibaba Cloud OSS / Amazon S3, etc.) as a drive letter on your PC (e.g. Z:), just like a local disk. The whole process takes about 3 minutes.

1. Before you start

  • Windows 10 / 11 computer (no other software required)
  • Get these three items from your administrator: Bucket name, AccessKey ID, AccessKey Secret

2. Download

⬇ Download CloudObjectStorageDrive-v0.1.zip (~17 KB)

If the button does not work, copy and paste this address into your browser:

https://github.com/sinopop/CloudObjectStorageDrive/releases/download/v0.1/CloudObjectStorageDrive-v0.1.zip

3. Installation steps

  1. Extract the downloaded zip to any folder (e.g. a new folder named "CloudDrive" on your desktop).
  2. Double-click CloudObjectStorageDrive.cmd (a normal double-click - no need to "Run as administrator").
  3. On first use two components (WinFsp, rclone) are installed automatically: click "Yes" on the system prompt and wait about 1-2 minutes.
  4. In the window that opens, pick the provider and region:
    • Alibaba Cloud OSS: select the region of your bucket (e.g. Singapore, East China 1 Hangzhou, etc.)
    • Amazon S3: select the matching region
    • Other S3-compatible storage: enter the Endpoint URL
  5. Enter the three items: Bucket name / AccessKey ID / AccessKey Secret.
    If your account is limited to a folder prefix, fill it in "Path (optional)", e.g. users/zhangsan; users with full-bucket access can leave it empty.
  6. Check "Auto-mount on sign-in" and click "Connect & Mount".
  7. Wait for "Mounted successfully", then click "Exit" to close the window.

4. Done

  • Open "This PC" - you will see the new drive (prefers Z:), usable like a normal local disk.
  • From now on it auto-mounts at sign-in and reconnects automatically after disconnects - no action needed.

5. FAQ

Access denied / cannot accessMake sure "Path (optional)" matches your folder prefix

6. Security note

Your AccessKey is like a password - do not share it with anyone. The tool stores the credentials only on your own computer. If you leave the team or suspect a leak, contact the administrator to disable it.

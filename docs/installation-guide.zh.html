☁️ Cloud Object Storage Drive 安装指引

把云端对象存储（阿里云 OSS / Amazon S3 等）挂载为电脑上的一个磁盘（如 Z: 盘），像本地磁盘一样使用。全流程约 3 分钟。

一、准备工作

  • Windows 10 / 11 电脑（无需安装其他任何软件）
  • 向管理员索取三项信息：Bucket 名称、AccessKey ID、AccessKey Secret

二、下载安装包

⬇ 点击下载 CloudObjectStorageDrive-v0.1.zip（约 17 KB）

如果点击无法下载，请复制以下地址到浏览器地址栏打开：

https://github.com/sinopop/CloudObjectStorageDrive/releases/download/v0.1/CloudObjectStorageDrive-v0.1.zip

提示：如果运行被系统拦截（智能应用控制提示「阻止了可能不安全的文件」）：请先解除锁定——选中解压出的所有文件，右键属性 → 勾选「解除锁定」→ 确定；或改用 7-Zip / WinRAR 解压（不会带网络标记）即可避免。

三、安装步骤

  1. 把下载的 zip 解压到任意文件夹（例如桌面新建的「CloudDrive」文件夹）。
  2. 双击 CloudObjectStorageDrive.cmd（普通双击即可，不需要右键“以管理员身份运行”）。
  3. 首次使用会自动安装两个组件（WinFsp、rclone）：弹出系统授权窗口时点击「是」，等待约 1–2 分钟。
  4. 在打开的窗口中，先选择服务商与区域：
    • 阿里云 OSS：选择你桶所在的地域（如新加坡、华东1 杭州等）
    • Amazon S3：选择对应区域
    • 其他 S3 兼容存储：填写 Endpoint 地址
  5. 填写三项信息：Bucket 名称 / AccessKey ID / AccessKey Secret。
    若你的账号被限制在某个目录，请在「目录（可选）」中填写，例如 users/zhangsan；整桶权限的用户留空即可。
  6. 勾选 「开机自动挂载」，点击 「连接并挂载」。
  7. 等待提示“挂载成功”，点击「退出」关闭窗口。

四、完成

  • 打开“此电脑”，即可看到新盘符（优先 Z: 盘），像普通磁盘一样使用。
  • 以后 开机自动挂载、断线自动重连，无需任何操作。

五、常见问题

问题解决方法
提示安装组件 / 弹出授权窗口点击「是」即可；若误点取消，重新点击「连接并挂载」再试
提示无法访问 / AccessDenied确认「目录（可选）」是否填了你的目录前缀
连接失败核对 Bucket / AccessKey / 区域是否正确，或联系管理员
如何卸载快速：工具内点「卸载」；完整（含依赖）：运行 Uninstall-cleanup.cmd
界面是英文窗口右上角可切换 中文 / EN

六、安全提醒

AccessKey 相当于账号密码，请勿转发给他人；本工具仅将凭证保存在你自己的电脑上。离职或怀疑泄露时，请及时联系管理员停用。
